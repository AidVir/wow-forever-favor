# WoW Forever · Merchant's Favor, Profession Leveling & Writs

Live site: https://aidvir.github.io/wow-forever-favor/

Three tools priced from the EU **PvP** ruleset auction houses (Alliance, Horde, optional Blackwater):

- **Merchant's Favor** (`index.html`): cheapest Waylaid Crate to fill per Favor.
- **Profession leveling** (`leveling.html`): cheapest 1–300 route for Alchemy, Blacksmithing, Enchanting,
  Engineering, Leatherworking, Tailoring, Cooking and First Aid, with shopping list and an estimate of
  what the crafts sell for on the AH (shown next to the vendor-only cost).
- **Craftsman's Writs** (`writs.html`): all 150 writs ranked by gold per 100 trade-faction reputation.

Prices are checked every 10 minutes; Blizzard publishes a new auction snapshot about once an hour,
and the job only downloads and commits when there is a new one.

- Ranks all 30 crates by gold per Favor (empty crate + cheapest accepted bundle).
- Prices the exact quantity from the cheapest listings, so thin markets are priced honestly.
- Optional "craft it yourself" pricing for Mining, Engineering, Tailoring and Leatherworking.
- Performance Bonus (Legacy) expected value, character-level filter, goal planner
  (e.g. 1,500 Favor for the Packmule Treat) that accounts for buying out cheap stock.

## How it works

`scripts/fetch-prices.mjs` runs hourly in GitHub Actions. It calls the Blizzard Game Data API
(`dynamic-forever-eu` namespace, `/data/wow/ruleset/1/auctions/{house}` and `/commodities`),
keeps the cheapest listings of every relevant item, and commits `data/prices.json`.
The static site (GitHub Pages) reads that file.

Crate data lives in `data/crates.js`, writs in `data/writs.js`. `data/recipes.json` is generated by
`scripts/build-recipes.mjs` from the Blizzard API (recipes, reagents), the live Forever client tables on
wago.tools (skill-up colours, patterns, crafting stations, cooldowns) and Classic data (trainer skill,
vendor prices). Re-run it after a game patch. Faction → auction house mapping can be pinned in `data/houses.json`.

## Setup

1. Create a client at https://develop.battle.net/access/clients.
2. Add repo secrets `BLIZZARD_CLIENT_ID` and `BLIZZARD_CLIENT_SECRET`.
3. Run the "Update AH prices" workflow once (Actions tab).

Local run: `BLIZZARD_CLIENT_ID=... BLIZZARD_CLIENT_SECRET=... node scripts/fetch-prices.mjs`
(`PROBE=1` prints the auction house index).
